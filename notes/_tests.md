## code  (verdict: pass)

The code holds together: every shader setting the renderer writes is one the shader reads, nothing is registered twice, storage is guarded, and no blocker or major fault turned up. What the user can run into are six small inconsistencies. Picking an equation preset silently switches off a cut they turned on themselves, while the Equation reset leaves a preset's cut on. Reset view and the equation presets can put the camera outside zoom limits the user typed. The Julia reset restores c but not the plane count a list entry changed. At n = 0 the scorecard contradicts itself, and a formula with a number of 1e15 or more fails with a misleading message. While a phase dial plays, the measured scorecard cells stay dimmed and stale until it is paused.

## maths  (verdict: pass)

The maths behind points 9, 10, 14 and 15 holds up: on z = 0 the Sphere inversions, Lathe, Mandelbulb and Split rules equal the ordinary complex power to rounding error for positive, negative and fractional n, and the real 2D view of the page matches a plain complex Mandelbrot grid pixel for pixel at n = 2 (classic Mandelbulb is the labelled exception). Two wording gaps: the Turn and longitude-phase dials do not say that they stop z = 0 matching the 2D picture (Lift and latitude phase do), and the note under the power dial describes the negative-power solid the wrong way round.
